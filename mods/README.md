# SourceDayZ mods

Mod files are committed as normal folder structures. Binary `.pbo` files use Git LFS; do not package the mod as ZIP, 7z, or RAR.

`@Helicopteros/Addons` contains the PBOs. `@Helicopteros/manifest.json` lists their relative paths, sizes, SHA-256 hashes, and public GitHub LFS URLs for the launcher.
